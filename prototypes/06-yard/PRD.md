# Yard — NL campus → GLTF

A one-shot product: type English at a Fort Worth data-center massing, watch halls / gensets / pond / fence change, download a `.glb`.

Not a BIM editor. The scene is a JSON spec (`campus.mjs`) rebuilt in Three.js. No model API key.

Audience: the same civic/hack room as Compute Works, when someone says “I just want to move the pond and export.”
